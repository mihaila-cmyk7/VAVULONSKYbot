# babel-bot

Telegram-бот, который ищет слова и фразы в [Вавилонской библиотеке](https://libraryofbabel.info)
и присылает расположение (гексагон, стена, полка, том, страница), фрагмент страницы с выделенным
текстом и ссылку на страницу.

## Возможности

- `/start`, `/help`, `/find <текст>`, `/translate <русский текст>` или просто обычное сообщение.
- Проверка ввода: нижний регистр автоматически, объяснение неподдерживаемых символов.
- Перевод русского текста на английский: кнопка «Перевести на английский и искать» и команда
  `/translate`. В библиотеку уходят настоящие английские слова («привет» → `hello`), а не
  транслитерация «privet».
- Лимит запроса 3200 символов (лимит со страницы поиска сайта).
- Кнопки: «Открыть на сайте», переключение режима (точное совпадение / внутри страницы),
  «Ещё один результат» (в режиме «внутри страницы»).
- Таймауты 12 с, 3 попытки при сетевых ошибках, понятные сообщения вместо падений.
- Ограничение: 1 запрос на пользователя в 3 секунды и не более 3 одновременных запросов к сайту.
- После результата бот присылает картинку страницы с выделенным найденным текстом (Pillow).
- Кэш результатов в памяти (1 час, до 256 запросов), лог-файл `babel_bot.log` с ротацией.

## Как получить токен

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте имя и username (должен оканчиваться на `bot`).
3. Скопируйте выданный токен вида `123456789:AA...`.

## Запуск

Нужен Python 3.11+.

```bash
cd babel-bot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # Windows: copy .env.example .env
# впишите токен в .env: BOT_TOKEN=...

python bot.py
```

Остановка: `Ctrl+C`. Ошибки пишутся в `babel_bot.log`.

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | запуск, хендлеры, ограничение частоты, кнопки |
| `babel_client.py` | запросы к сайту (с повторами и кэшем) и разбор ответа |
| `validators.py` | проверка, нормализация, транслитерация |
| `translator.py` | перевод русского текста на английский (Яндекс, Google, MyMemory) |
| `formatters.py` | тексты сообщений, фрагмент с выделением, клавиатуры |
| `page_image.py` | рисует скриншот страницы (80×40 символов) с подсвеченным найденным текстом |
| `fonts/` | моноширинный шрифт DejaVu Sans Mono для скриншота |
| `local_library.py` | встроенная обратимая «библиотека» на случай, когда сайт недоступен |

## Если сайт изменит разметку

Все предположения о сайте собраны в начале `babel_client.py` (блок `DEFAULT_*`, регулярное выражение
`LOCATION_RE`, список `PAGE_TEXT_IDS`). Клиент сначала пытается прочитать форму со страницы
`search.html`, и только потом использует значения по умолчанию. Если бот отвечает «неожиданный
формат», откройте `babel_bot.log` и поправьте эти константы.

## Перевод на английский

Библиотека состоит только из латиницы, поэтому русский запрос бессмысленно транслитерировать:
«privet» — не английское слово, искать его в библиотеке нечего. Бот именно переводит текст:

- команда `/translate привет, мир` — только перевод, с кнопкой «Искать перевод в библиотеке»;
- кнопка «Перевести на английский и искать» — перевод и сразу поиск;
- кнопка «Транслитерировать и искать» осталась для тех, кому нужна именно запись латиницей.

Перевод берётся у бесплатных сервисов по очереди: Яндекс.Переводчик (если задан ключ), Google,
MyMemory. Результат кэшируется на час. Если все сервисы недоступны, бот честно пишет об ошибке и
предлагает транслитерацию, а не подставляет искажённые слова.

Настройки в `.env`:

```ini
# auto | google | yandex | mymemory (можно список через запятую)
TRANSLATE_SOURCE=auto
# Ключ Яндекс.Переводчика, необязательно
YANDEX_TRANSLATE_KEY=
```

Пунктуация перевода приводится к алфавиту библиотеки (запятая, точка, пробел), слова при этом не
меняются. Если в переводе остаются цифры или другие недопустимые символы, бот показывает их и не ищет.
Ответы, похожие на транслитерацию или мусор (например, «r te6r»), отбрасываются: лучше честная ошибка,
чем искажённые слова.

Текст, отправленный на перевод, уходит на выбранный сервис (Яндекс, Google или MyMemory); в библиотеку
попадает уже английский запрос.

## Проверьте вручную

Сайт не отдаёт разметку в автоматическом режиме, поэтому перед использованием проверьте в браузере
(DevTools, вкладка Network) один поиск и сверьте:

1. URL и метод отправки поиска (по умолчанию `POST search.cgi`).
2. Имя поля с текстом (по умолчанию `find`) и поле/значения режимов (по умолчанию `method`: `x` и `m`).
3. Где в ответе лежит текст страницы (по умолчанию элемент с `id="textblock"`, затем `<pre>`).
4. Что в ответе есть ссылка вида `book.cgi?<hex>-wN-sN-vNN:<страница>`.

## Запасной режим (если сайт недоступен)

Если libraryofbabel.info не отвечает или блокирует запросы с сервера (часто бывает с хостингов вроде Render),
бот не показывает ошибку, а ищет во встроенной локальной библиотеке (`local_library.py`). Правила те же
(3200 символов, 29 знаков, стены/полки/тома/страницы), текст находится всегда, но адрес относится только
к этой встроенной библиотеке и на сайте по нему ничего не откроется. В сообщении это помечено.
После сбоя бот 5 минут не ходит на сайт и сразу отвечает локально, потом пробует снова.

Переменная `BABEL_SOURCE`: `auto` (по умолчанию), `site` (только сайт, с ошибками), `local` (только локально).

Нейросеть для поиска не подходит: она не умеет вычислять адрес страницы и будет выдумывать координаты.
